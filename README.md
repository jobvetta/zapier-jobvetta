# Jobvetta for Zapier

Official Zapier Platform CLI (`19.3.0`) integration for [Jobvetta](https://www.jobvetta.com) (`App251803`).

- **Accept Zapier Invite**: https://zapier.com/developer/public-invite/251803/cc09b46dccd4bd32d821d7d0f051d489/
- **API Docs and Free API Key**: https://www.jobvetta.com/api

## Triggers and Actions

- **Trigger (`new_job`)**: *New Job Matching Search* - Triggers when a new verified employer career-site job posting matches your role, location, or remote filters.
- **Search (`find_jobs`)**: *Find Jobs* - Finds live verified employer job postings matching a role keyword, location, or remote filter.
- **Search (`find_company_jobs`)**: *Find Company Hiring Signals* - Finds active job openings and hiring velocity counts for a specific employer.
- **Search (`estimate_salary`)**: *Find Market Salary Benchmark* - Finds live P25, median (P50), and P75 base salary benchmarks from disclosed employer job postings.
- **Search (`find_job_by_id`)**: *Find Job by ID* - Finds full job description, qualifications, extracted skills, and compensation details by Job ID.
